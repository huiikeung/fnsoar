## 一、全新功能

### 1. 订阅体系重构：聚合 / 单订双模式

- **聚合模式**：所有订阅的 provider 合并进默认配置，规则/策略组全局共用；订阅卡片改为**紧凑成员行**，操作按钮收敛到总览卡；支持**拖拽排序**与**拖到「未参与聚合」区移出聚合**（移出=注释掉 provider 块，只重启引擎面板不断，约 2 秒生效）
- **单订模式**：点击卡片即切换为该订阅的独立配置（promote 为运行配置），**热重载**实现——不再整链重启，TUN/系统代理等运行态不丢失；正在使用的订阅有绿点标记
- 单订卡片显示**当前订阅的节点数/用量**（剩余流量、已用、总量、到期、行内进度条）；严格单行排版，箭头展开操作
- **编辑选项菜单**（参考 Clash Verge Rev profile menu）：设为当前使用 / 资料 / 编辑文件 / 规则 / 节点 / 代理组 / 扩展覆写配置 / 扩展脚本 / 打开文件 / 更新 / 更新(走代理) / 分享二维码
- **本地配置上传**（Clash 完整配置或 base64 节点列表）、订阅链接导入（就绪三态）、导入前名称探测
- 聚合开关在「设置 → 高级设置」，切换即时生效；从未选择时默认取第一个订阅；前端即时反馈
- 排除名单持久化 + 防抖重启（连续拖多次只重启一次）

### 2. chains 可视化编辑器（规则 / 节点 / 代理组）

- 三段独立编辑器：**规则**（类型/内容/代理策略下拉 + 前插/后插/删除）、**节点**、**代理组**（类型/名称/图标/URL/间隔）
- 左侧添加表单 + 右侧**订阅原有条目**展示（点垃圾桶加入删除名单）；高级模式为带行号的 YAML 源码
- 弹窗支持**右下角自由拉伸**，编辑器跟随伸缩；与全局扩展弹窗 UI 统一（自定义下拉、加高按钮、Verge 同款箭头）

### 3. 全局扩展 / 每订阅独立扩展（对齐 Clash Verge Rev）

- 订阅页新增**全局扩展**模块：**覆写配置**（深合并模板，字典递归合并/列表整体覆盖）+ **全局脚本**（本机 node 执行，超时 10 秒，缺失/报错自动跳过）
- **每订阅独立扩展**：merge / script 各自独立弹窗，仅对该订阅的导入/更新生效
- 执行顺序完整声明：订阅原文 + 应用设置 → 全局扩展配置 → 全局扩展脚本 → 应用设置回写

### 4. 弹窗化源文件编辑 + fnOS 宿主桥

- **编辑源文件统一弹窗**：配置页、聚合「编辑默认配置文件 → 编辑源文件」、单订卡片「编辑文件」三个入口一致——标题/提示语自适应、**左侧行号栏**、**右侧滑动块**（可拖拽/点轨跳转/内容不满自动隐藏）、重新加载/取消/保存
- 保存 config.yaml 自动重启服务；保存订阅文件自动重建节点索引
- **「打开文件」改用 fnOS 宿主桥 `openFile` 直接打开文件**，失败自动回退所在目录 → 复制路径；「打开配置目录」保持开目录行为
- 代码编辑器从 textarea 改为 **contenteditable div**，彻底消除 WebView 默认聚焦外观（圆角光环/蓝边）

### 5. 流量隧道管理 + 更新日志弹窗

- **流量隧道**：mihomo listeners tunnel 的可视化增删（target/network）
- **更新日志弹窗**：GitHub releases（atom 兜底 + 本地 CHANGELOG.md）

### 6. 内核 / 面板 / GEO 管理

- 内核管理（更新弹窗 / 重启内核 / 版本徽章）迁入「Clash 核心」弹窗；GitHub API 限流期也能检测新版本
- 面板（Zashboard/Metacubexd）与 GEO 数据**「有版本更新」红色徽章即点即更新**
- GEO 数据管理：自动更新开关（缺省打开）+ 文件卡片（状态/大小/时间）+ 来源 URL 配置 + ASN 显示
- **软件图标切换**（fnOS 桌面与窗口图标）

### 7. 配置页重构

- **DNS 设置**重构为五标签模块（DNS/默认/备用的/策略/Hosts 映射）
- **TUN 设置**：Stack / MTU / 自动路由 / 自动检测出口网卡 / DNS 劫持 / 严格路由 / 排除自定义网段，完整详细设置
- **网络端口**：Mixed/Socks/Redir/Tproxy/控制器端口/统一延迟/IPv6/Allow-Lan/Bind-Address；「认证」正名为**代理认证**
- **测速参数**：URL/超时/并发；**订阅节点过滤**：名称关键词 + 名称正则（PCRE）
- 全部模块：可视化编辑 + 「编辑源文件」弹窗 + 重置；窄屏按控件类型分治（开关不换行/小字可换行/输入框溢出才换行）

### 8. 流量趋势图重构（参考 Clash Verge Rev）

- 1/5/10 分钟切换、二次曲线中点法平滑（自然防过冲）、渐变面积填充、平滑/线性切换、禁负值、DPR 高清渲染、持久化缓存

### 9. 系统代理 / TUN 快捷控制

- 首页「网络设置」卡片双标签（系统代理 / 虚拟网卡模式）+ 运行状态
- 系统代理：HTTP_PROXY/HTTPS_PROXY/ALL_PROXY/NO_PROXY 环境变量托管（/etc/environment、/etc/profile、/etc/bash.bashrc），端口自动跟随 Mixed Port，「当前检测结果」区即时刷新，四态动态提示（按 TUN 状态）
- TUN 关闭时引擎自动启用 **nftables 透明接管（host-redirect）**，覆盖本机 TCP 与 DNS

### 10. 策略组三视图 + 首页模块自定义

- 策略组页：全部 / 策略组（业务分流）/ 节点组（地域）三视图图标切换，默认随聚合模式选择
- 首页模块（订阅信息/当前节点/代理模式/网络设置/网站测试/IP/Clash/系统/流量统计）可逐项显隐

## 二、修复（82 项，按域分组）

### 订阅 / 聚合 / 拖拽（约 30 项）

- 打开聚合后订阅页面不变过来（_provAgg 陈旧 + 快照按旧模式还原）；单订模式切到订阅页闪其他样式；刷新闪旧卡片（快照带构建戳）
- 单订卡片显示当前订阅的节点数/用量（切过去全空）；关闭聚合即时生效 + 默认第一个订阅；单订卡片严格单行排版、箭头位置与气泡
- 拖拽后序号不更新 / 被排除卡片重启后跑回聚合区 → 防抖重启；拖拽占位符不消失/不恢复（drop 处理器找旧类名）；拖拽指示条残留
- 未参与聚合区改为独立区域（不再嵌套）+ 占位汉化 + 宽度修正（漏 grid-column:1/-1）
- 修复订阅聚合区一段 JS 语法错误（曾导致面板全站点击失效）；代理组可视化不显示（YAML 列表项顶格）；紧凑行拖拽与视觉细节
- 移除可选链 `?.`（2 处）——旧 WebView 解析失败会导致 APP 整个脚本崩溃（页面能显示但所有点击无反应）
- configVisual 多余 `</div>` 导致 main 容器被提前关闭——日志/测试/设置/原始配置页全部白屏
- Sniffer 开关写入废键 + section no-op 误报 400；外部 UI 默认值 dashboard → zashboard

### 弹窗 / 编辑器（约 15 项）

- **弹窗嵌套在隐藏 section 内**导致从配置页打开「编辑源文件」零尺寸不显示（弹窗移至 body 级）
- **`.ce-area` 规则未闭合 + 孤括号**把自定义滑块样式整段吞掉（滑块不可见）
- 弹窗拉伸后编辑器不跟随伸缩（固定 330px，拖大后一片死白）；chains/订阅文件/每订阅扩展弹窗固定高度内部滚动
- 英文界面下**首页模块设置弹窗失效**（语言遍历改写 title 致选择器失配、弹窗被即时关闭）——改 id 选择器；同案修复首页「测速」按钮
- 弹窗定位加视口夹取（防个别设备把弹窗挤出屏幕外）；全局提示气泡箭头方向 + 浅色模式背景
- TUN 帮助提示靠近弹窗顶部时自动向下翻转（被 mx-body 裁掉）；系统代理/TUN 弹窗透明背景（--mx-panel 未定义）；跟随系统-深色 mx-\* 仍白底 / 浅色文字发白（--mx-text 漏分号）

### 图标 / 桌面（约 11 项）

- 桌面图标真正来源是 ui/images/icon\_{0}.png（不是 favicon），补 build.sh 部署；图标比其他 app 小一圈（favicon 透明边）；IP 信息国旗改本地 SVG（emoji 旗帜在 Windows 必现方框）
- 虚拟网卡图标左右箭头对称；TUN 标签图标改盾牌 VPN（小尺寸发虚缺块）；网络端口图标改 share-nodes；DNS 标题图标改地球

### TUN / 系统代理 / 网络（约 12 项）

- TUN 自环导致系统网络瘫痪 + 外来内核误判；TUN 两界面与源文件不对齐（配置页漏加载 auto-route/auto-detect-interface）；协议栈选项统一
- 「打开配置文件仍无响应——宿主桥 openFileManager 只接受目录」；订阅节点过滤两区域深色模式白底；DNS 字段保存保持原格式（修复保存写坏配置）
- 系统代理「当前检测结果」之前一直空/不更新；MTU 输入框宽度；应用范围开关同行对齐；「跟随 Mixed Port」中文化、服务地址只显示实际地址
- 窄视口输入框溢出 + socks/redir/tproxy/external-ui 未从配置加载；输入框/下拉点击后蓝框不消失

### 窄屏 / 手机端（约 10 项）

- 手机端 CSS 裸奔在顶层导致电脑版也被隐藏（补回 @media 包裹）；设置页卡片收拢单列；桌面端用量靠最右（移动规则泄漏全局）
- 窄屏配置页输入框/开关/下拉同行不换行；Clash 信息卡片允许局域网/模式不显示数据

### 构建戳 / WebView 缓存（约 4 项）

- 页面缓存自愈改为**接口验伪**（修旧 HTML 里旧戳自证清白的死局）；构建戳强制刷新 + 会话内有限重试

### 其他

- Clash 信息卡片规则数量标签中文化；系统信息「平台」单行；趋势图曲线贝塞尔过冲越界（负值实为过冲）；内核/应用更新检测在 GitHub API 限流期失效；GEO 更新失效（改面板直下载）等

## 六、升级说明
