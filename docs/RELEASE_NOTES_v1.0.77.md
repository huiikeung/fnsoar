## fnSoar v1.0.77

### 策略组视图 · 三视图切换（本次重点）

- 策略组页新增 **全部 / 策略组 / 节点组** 三视图切换（规则模式下显示）：「策略组」只显示业务分流组，「节点组」只显示地域组（自动/手动/故转/均衡），「全部」为二者之和；计数按实时数据统计
- 三个视图为**图标按钮**（全部=宫格、策略组=分层、节点组=节点树），选中只变蓝（accent 色）不带蓝色背景；所选视图名称 + 数量显示在最右侧
- 视图切换行独立在模式切换（规则/全局/直连）下方，仅规则模式出现（全局/直连隐藏）
- 默认显示「策略组」

### 地域组显示

- 去掉「显示地域组」独立开关，由三视图切换统一接管
- 子卡片第二行沿用「订阅名称 ｜ 节点名称」格式（无徽章）

### 配置模板（默认配置）

- `default-config/config.yaml` 更新为干净模板：无均衡组、无订阅，安装向导填订阅后使用
- rule-anchor 的 `class` 锚点并入 `User-Agent` header（下载请求标识），供 `<<: *class` 的规则集继承
- 移除模板末尾游离的坏格式 `header`（此前导致 YAML 无法解析）

### 修复

- 修复策略组页面：重新打包基于当前运行配置一致的最新代码
- 移除 8 个均衡组及其全体引用（default 锚点 / 业务组 proxies 列表），引用完整性校验通过
