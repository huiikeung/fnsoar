## fnSoar v1.0.76

### 策略组 · 测速与切换（本次重点）

- **测速重构：成员组递归展开实测**——主卡点「测速」时，`xx-手动` 这类成员策略组不再拿组名直接测（对 Selector 不可靠），而是递归展开其下**全部真实节点**并发 6 路实测；叶子健康的手动组从此有延迟数据，死节点明确显示「超时」
- **测完自动选最快**：全部测完后，Selector 类成员组自动切换到自己名下延迟最低的节点并弹提示；URLTest / Fallback / LoadBalance 保持引擎自管选路，不强切
- 此前版本每组头部的 ⚡ 按钮已移除（由测速流程统一承担）

### 性能

- **策略组 / 订阅页秒开**：上次渲染快照（内存 + localStorage）先铺底，卡片、图标、名称、状态瞬时可见，数据后台刷新原位重绘；引擎重启等待窗口不再闪「加载中…」（热切换 ~30ms 出卡）

### 界面

- 日志页支持右下角一键回顶（列表内滚容器，与全局模式共用按钮）
- 子卡片第二行显示当前节点**归属订阅徽标**（低调样式，与节点协议标签同款）
- 首页订阅卡「已使用 / 总量」图标换为完整的数据库字形
