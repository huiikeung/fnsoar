密钥 与 代理认证 的区别　控制器端口 + 密钥 管理「控制入口」：fnSoar 面板、Zashboard、Metacubexd 等通过控制器端口调用内核管理 API，密钥是调用密码，防止他人远程切换节点 / 查看连接 / 改配置。「代理认证」在「网络端口」模块单独设置，管设备经 7890 / 7891 上网时的用户名密码——密钥管「谁能控制代理」，代理认证管「谁能使用代理」，两者互不影响。

端口用途说明　混合端口是 HTTP + SOCKS5 二合一入口，手机 / 电脑代理填它即可；HTTP / Socks 端口留空则不单独监听；Redir / TProxy 供路由器等透明代理场景使用；监听地址 * 表示允许局域网设备连接；「代理认证」即其他设备经这些端口上网时要填的用户名密码。控制器端口（管理 API）在「基础设置」模块设置。
